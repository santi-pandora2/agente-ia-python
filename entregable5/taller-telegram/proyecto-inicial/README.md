# Proyecto inicial del bot del spa

Abre esta carpeta en OpenCode y sigue TALLER.md, ubicado en la carpeta superior del paquete.

Esta carpeta es el punto de partida. Incluye reglas, especificación y scripts de conexión; OpenCode construirá la función, la migración y las pruebas a partir de los prompts del taller. Todavía no contiene el bot terminado.

No necesitas escribir TypeScript o SQL manualmente. Sí necesitas crear las cuentas, llenar las variables en privado, ejecutar el SQL generado y comprobar la conversación en Telegram.

No pegues tokens en OpenCode. Copia .env.example a .env y edítalo tú. El archivo .env queda fuera de Git. Las restricciones de herramientas ayudan, pero no son un aislamiento de sistema: no autorices comandos que lean o impriman secretos.
